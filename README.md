# 🧗 KletterApp

Eine Web-App für Kletterer – entdecke Routen in deiner Halle oder am Outdoor-Gelände, logge deine Begehungen und verfolge deinen Fortschritt.

## 😊 Features

- **Hallensuche** – Finde Kletterhallen und Outdoor-Gebiete
- **Interaktive Karte** – Sieh alle Wände und Routen auf einen Blick
- **Routendetails** – Farbe, Schwierigkeit, Beschreibung und Kommentare
- **Projektliste & Favoriten** – Markiere Routen, die du angehen willst
- **Begehungs-Log** – Logge geschaffte Routen
- **Profil** – Bewundere deinen Fortschritt und messe dich mit deinen Freunden

## 🛠️ Tech Stack

| Bereich   | Technologie |
| --------- | ----------- |
| Frontend  | React       |
| Backend   | Spring Boot |
| Datenbank | PostgreSQL  |
| Auth      | Keycloak    |

## 🧗🏼 Getting Started

> **Voraussetzung:** [Docker](https://docs.docker.com/get-docker/) mit Compose Plugin

### 1. Release herunterladen

Lade das neueste Release als ZIP herunter:
[📦 Neuestes Release](https://github.com/SweetQuaternion/KletterApp/releases/latest)

Entpacken und in den Ordner wechseln:

```bash
unzip kletterapp.zip
cd kletterapp
```

### 2. Installer ausführen

```bash
chmod +x install.sh
./install.sh
```

Das Skript richtet alles ein – Volumes, Konfiguration und startet die App automatisch.
